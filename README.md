#   soda's Blog

基于 [Fuwari](https://github.com/saicaca/fuwari) 搭建的个人博客。

> Fuwari 是一个基于 [Astro](https://astro.build) 构建的静态博客模板，拥有简洁的设计和流畅的动画效果。

##   关于本站

这里记录日常随笔、技术笔记和一些杂七杂八的想法。没有什么特定的主题方向，想到什么写什么。

##   技术栈

- **框架**: Astro
- **主题**: Fuwari
- **样式**: Tailwind CSS
- **部署**: 待定

##   本地开发

```bash
pnpm install
pnpm dev
```

访问 `http://localhost:4321`

##   构建

```bash
pnpm build
```
